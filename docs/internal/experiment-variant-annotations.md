# Experiment variant annotations

The Metrics tab shows a Variant annotations panel beside the experiment results. Notes belong to individual variants and do not affect the experiment's conclusion.

Use the filter above the notes to show **All** annotations or focus on one variant. Each option shows its note count, including variants with no notes. Counts reflect all annotations, regardless of the selected filter.

Selecting a variant also selects it in the annotation composer. Switching filters preserves any draft text. After adding a note, the composer keeps its selected variant.

A variant with no annotations shows a message inviting you to add a note or choose another variant. The All view shows the experiment-wide empty state when there are no annotations at all.
