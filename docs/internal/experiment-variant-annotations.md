# Experiment variant annotations

The Metrics tab shows persistent notes for individual experiment variants. These
notes are separate from the experiment's conclusion and conclusion comment.

When ending an experiment with a variant selected, the modal offers an optional
variant note. The field starts empty each time the modal opens. Leaving it blank
ships the variant without creating an annotation.

The note saves only after the variant ships successfully. A saved note appears in
the variant annotations panel without reloading the page. If the note cannot save,
the variant stays shipped and an error explains how to retry. The panel keeps the
note text and selected variant ready for the user to click **Add annotation**.

Ending without selecting a variant, or a failed ship request, creates no note.
